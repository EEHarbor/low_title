Low Title

Low Title retrieves an entry title, category name, channel title, or site label with a single template tag. Read the Tag Reference to choose an identifier and output the corresponding label.

Compatibility

These instructions cover Low Title 4.0.2 and the modern ExpressionEngine add-on layout. The package metadata requires ExpressionEngine 3 or later; its release history records support through ExpressionEngine 7 and PHP 8. Choose a package version appropriate for your installation. The historical EE1 and EE2 packages use different files and are not the current installation workflow.

Installation

  1. Download and extract Low Title.
  2. Copy the package’s low_title folder to system/user/addons/, so that addon.setup.php is directly inside the installed low_title folder.
  3. Open Developer → Add-Ons in the ExpressionEngine control panel, find Low Title, and click Install.

These control-panel labels follow ExpressionEngine 7. Use your configured system directory if it has been renamed. This package supplies no separate theme files.

See the release notes before changing package versions. Historical EE2 installation text is preserved in the repository under archive/legacy-documentation/, outside the active documentation.
